# Vendeo

Vendeo is a web app prototype that helps local businesses manage online orders, in-store sales, and inventory from one dashboard.

## Features

- Live order board with order status tracking
- Product catalog and inventory management
- In-store sales with automatic stock updates
- Product bundles with promotional pricing and expiration dates
- Restocking forecasts based on recent sales
- Multi-store data structure

## Built with

- React
- Vite
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore
